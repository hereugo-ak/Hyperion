# README Brand Asset Validation

The generated `assets/brand/hyperion-tui-wordmark.png` was visually checked on 2026-08-12. It presents the complete six-line ANSI Shadow HYPERION wordmark on the TUI dark canvas (`#141413`) and clearly transitions left-to-right from soft clay through clay to deep clay.

The corresponding SVG preserves the same exact character source and per-cell color calculation, but a viewer without the required block-glyph font can substitute missing glyphs. The README therefore embeds the PNG for cross-compatible rendering, while retaining the SVG as the inspectable vector artifact. Both files are deterministically regenerated by `tools/generate_tui_wordmark_svg.py` from `hyperion.tui.banner.WORDMARK`, `hyperion.tui.theme.LOGO_STOPS`, and `hyperion.tui.motion.color.ramp`.
